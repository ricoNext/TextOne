# TextOne · UI 对齐规格（macOS）

> 目标：同一篇笔记并排打开时，三栏比例、行高、字号、颜色、分隔线一致。
> 允许的差异：交通灯由系统绘制、字体次像素渲染、文本编辑手感、原生右键菜单。

所有数值来自 MiaoYan `0f348ca9` 的代码，不是从截图上估的。截图里的栏宽多数是用户拖过的，不要照抄。

## 1. 窗口与三栏

| 项 | 值 | 来源 |
|---|---|---|
| 默认窗口 | 1100 × 700 | `ShellWindowController` |
| 最小窗口 | 960 × 600 | 同上 |
| 顶栏高度 | 52 | `ShellStyle.headerHeight` |
| 交通灯预留 | 左 78 | `ShellStyle.trafficLightsInset` |
| 交通灯旁控件起点 | 92 | `LayoutConstants.besideTrafficLights` |
| 侧栏宽度 | 138（下限）– 280（上限），首屏 170 | `LayoutConstants` + storyboard |
| 笔记列表宽度 | 280（默认），220（最小） | `defaultNotelistWidth`、`noteListMinimumWidth` |
| 侧栏折叠吸附 | 86 | `sidebarCollapseSnapWidth` |
| 列表折叠吸附 | 180 | `noteListCollapseSnapWidth` |
| 分隔线 | 1px，横向贯穿 | `Theme.columnHairline` |

布局用 `grid-template-columns: sidebar 1px list 1px 1fr`。分隔线用独立的 1px 列，不要用 border，避免拖拽时抖动。

## 3. 字体与字号

| 位置 | 字号 | 字重 |
|---|---|---|
| 侧栏文件夹 | 14 | 400 |
| 列表标题 | 14 | 400 |
| 列表日期 | 12 | 400 |
| 编辑器 | 16（默认） | 400 |
| 预览 | 16（默认） | 400 |
| 演示 | 24（默认） | — |
| 界面最小字号 | 12 | — |

- 界面字体：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", sans-serif`。
- 品牌字：LXGW WenKai 的 `MiaoYanMark.ttf` 子集；TextOne 需要重新裁一份 `TextOne` 字标，只保留需要的字形。
- 字距：`0.02em`，侧栏、列表、预览正文统一。
- 行高：多行文本 1.45em；编辑器和预览正文 1.6。

## 4. 行高与间距

| 项 | 值 |
|---|---|
| 侧栏文件夹行 | 32 |
| 侧栏品牌行 | 63.5（52 + 9 + 2.5） |
| 笔记列表行 | 52 |
| 选中 pill 圆角 | 8 |
| 选中 pill 内缩 | 横 6 / 纵 3 |
| 列表内容右缩进 | 30 |
| 浮动层圆角 | 10（查找栏、TOC、Toast） |
| 输入框圆角 | 8 |
| 列表行线缩进 | 左右各 20，止于标题起点 |

笔记列表行线有个容易漏的规则：选中行和它上一行的行线要隐藏。AppKit 版用 `isNextRowSelected` 做，React 用 `:has(+ .selected)` 或索引判断。

## 5. 组件状态

- **选中**：只换底色 pill，不加边框、不加阴影、不改字重。
- **悬停**：控件底色从 6% 提到 9%；行本身不整行变色。
- **焦点**：输入框不画额外 focus ring，靠光标和底色区分。
- **禁用**：文字降到三级灰，不降透明度（透明度会让纸色透出来，发脏）。
- **按钮**：只有图标或「图标 + 12pt 文字」两种；不加圆角矩形底，除非是工具栏的 pill 按钮。
- **空状态**：居中的鸟插画 + 一行 12pt 提示，不放大标题。

## 6. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 悬停、按下反馈 | 0.12s | ease-out |
| 栏宽、选中、主题切换 | 0.25s | ease-out |
| 预览内容淡入 | 0.08s | linear |

不要弹跳、不要 spring、不要缩放超过 1.02。

## 7. React 实现约定

- 所有 token 放在 `src/styles/tokens.css`，组件只引用变量，不写死颜色。
- 不用 UI 组件库，不用 Tailwind 默认色板。默认色板一进来，纸色和暖灰就会偏冷。
- 不用 `box-shadow`，浮动层除外（`Theme.FloatingShadow` 的数值后续补）。
- 圆角只用 8 / 10 两档；不要 `rounded-xl`。
- 字体平滑保持默认；深色下不要开 `antialiased`，正文会变细。
- 三栏用 CSS Grid，滚动容器分别是列表和编辑区，不要让 `body` 滚。

## 8. 对不齐的部分

| 项 | 原因 | 处理 |
|---|---|---|
| 交通灯位置 | 系统绘制，Tauri 只能设 `trafficLightPosition` | 允许 1–2pt 偏差 |
| 原生菜单 | Tauri 菜单由系统渲染 | 字体与间距跟随系统即可 |
| 文本输入手感 | CodeMirror 不是 NSTextView | 只验收光标、选区、输入法可用 |
| 右键菜单 | Web 菜单不是 NSMenu | 先做功能，样式后补 |
| 滚动惯性 | WKWebView 与 NSScrollView 不同 | 不验收曲线，只验收位置同步 |

## 9. 验收方法

1. 同一篇笔记，MiaoYan 与 TextOne 并排，窗口都设为 1100 × 700。
2. 截图叠加，检查三栏边界、顶栏基线、列表行高、选中 pill 位置。
3. 用取色器核对纸色、主文字、选中底色、分隔线。
4. 量四行文字：侧栏 14、列表标题 14、日期 12、编辑器 16。
5. 连续滚动 10 秒，检查预览与编辑器的行号是否漂移。
6. 切换浅色/深色，确认没有一处仍是另一套主题的颜色。

前五项是硬指标；第六项只要出现一处漏改，就算不通过。

## 10. 复核记录（2026-11-20，实现时二次核对）

第一版规格是从 `Theme.swift` 与 `Shell*/` 读出来的，动手写 React 时又对着 storyboard
与 `SearchTextField.swift`、`NoteRowView.swift` 逐条量了一遍，下面这些要以此为准。

### 10.1 笔记列表顶部是搜索框，不是文件夹名

`Main.storyboard` 里 `SidebarNotesView` 的头部只有一个 `SearchTextField`（x=13、宽 222、高 30）
加一个 20×20 的 `newNote` 按钮（右边距 12）。`SearchTextField.swift` 里
`searchButtonCell = nil`、`cancelButtonCell = nil`，所以**放大镜和清除按钮都不画**，
只有一个占位符 `Search` 和一圈发丝边框。

- 高 30、全圆角（半径 15）、底色 = 纸色、1px `hairlineColor`
- 文字内缩 12，字号 12（`searchFontSize = 12`）
- 聚焦不画 focus ring，只靠光标

文件夹名不出现在列表列，只出现在侧栏选中项里。

### 10.2 列表行卡片的准确几何

`NoteRowView.selectionRect()`：左右各缩 8、上下各缩 2，圆角 8。
`NoteCellView` 的约束：标题 top=9.5、leading=3（相对 cell）、右对齐到 cell 右边；
日期 bottom=7.5、与标题左对齐；图钉 12×12，leading = 日期.trailing + 5，centerY = 日期.centerY + 1。

换算到列坐标（cell 左边距约 17）：标题与日期都在 x=20，正好与 1px 行线的缩进对齐。
行线在选中行、以及选中行的**上一行**都不画（`isNextRowSelected`）。

### 10.3 侧栏品牌锁形

`ShellSidebarBrand`：鸟 24×24、间距 6、文字下移 2、整行高 36，左右各缩 8。
拉丁名字号 = `nameFontSize`（14），中文 +2；`brandWordmarkFont` 对拉丁名回落到
**Charter-Roman**，所以 TextOne 的字标应该用 Charter，不是 LXGW 文楷的子集字体。
字距：拉丁名不加额外字距（只有 0.02em 的标签字距）。

侧栏行：图标 20、间距 6、行高 32、缩进 14/层；选中 pill 左右缩 6、上下缩 3、圆角 8。

### 10.4 颜色：深色下选中态是实色，不是白色透明度

| 角色 | 浅色 | 深色 |
|---|---|---|
| 侧栏选中 | `#E8E6DC` | `#302F2D`（实色） |
| 列表选中 | `#EFEDE4` | `#2E2D2B`（实色） |
| 分栏线 / 行线 基色 | `#1F1E1C` @7% / @13% | 白 @7% / @6.5% |
| 输入框底 | `#1F1E1C` @4.5% | 白 @6% |

行线基色是 `#1F1E1C`（`Theme.columnHairline` / `noteRowHairline` 的 dynamic 参数），
不是主文字色 `#363433`；用错会让线偏暖和偏深。

### 10.5 编辑器语法色（深色补齐）

| 语法 | 浅色 | 深色 |
|---|---|---|
| 标题 | `#5E3DB3` | `#8E6AD9` |
| 粗体 / 删除线 / HTML | `#9A7400` | `#DAAE76` |
| 链接 / 高亮 | `#24837B` | `#58D8AD` |
| 列表符 / 标点 | `#7A7872` | `#8E8B83` |
| 正文 | `#403E3C` | `#D5D4D6` |
| 行内代码 / 围栏 | `#B89D4B` | `#BE9868` |

编辑器**不放大标题**，只上色。这一点和预览不同（预览 h1 = 1.76em、h2 = 1.41em、h3 = 1.18em）。

### 10.6 两处有意偏离

1. **侧栏顶栏保留 52pt 操作带**（`ShellSidebar` 的写法：左侧 78 让给交通灯，右侧放
   新建文件夹、切换列表两个按钮），品牌行放在操作带下方。
   AppKit 版把品牌行贴着窗口顶边（63.5 行高），与交通灯在垂直方向只差 6pt，WebView
   里无法保证不撞；而且去掉顶栏就没有新建文件夹的入口。
2. **列表头用搜索框，同时不再显示文件夹名**（按 10.1 回到 AppKit 版）。
   侧栏的选中项已经说明了当前文件夹。

其余数值按第一版规格执行。

### 10.7 列表行改为三行卡片（2026-11-22）

`01-feature-inventory.md` 的 B2 要求「标题、正文摘要、修改日期」，AppKit 版的
`NoteCellView` 只有标题和日期，摘要只在 SwiftUI 外壳里有。按 B2 实现成外壳的样子：

- 标题 14、摘要 13（`--ink-2`，最多两行）、日期 12（`--ink-3`）
- 行高由内容决定，下限仍是 52；卡片内边距 9.5 / 8 / 8 / 12
- 摘要由扫描时读取文件头部生成，去掉 frontmatter、围栏代码、图片、链接地址与标记符，
  截到 90 字

搜索结果复用同一张卡片：摘要位置换成命中的那一行，日期不显示。
